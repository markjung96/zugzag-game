# Phase 3 — 멀티 크루 & 자동화 (확장 단계)

> **완료 조건**: 다른 크루 1곳 이상이 자기네 시즌을 독립적으로 운영한다.

---

## 3.1 크루 대항전 매치

- [ ] `game_matches` 테이블 (`match_id`, `crew_a_id`, `crew_b_id`, 공유 정책, 기간)
- [ ] `sessions.team_mode='crew_vs_crew'` 활성
- [ ] 양 크루 멤버가 같은 라이브 보드 — `/match/{id}`
- [ ] 크루 점수 = 상위 N명 합산
- [ ] 매치 종료 시 승자/무승부 표시
- [ ] 멀티크루 시 display_tokens 정책 재검토 (양 크루 토큰 발급 권한)

## 3.2 자동 배지 (zugzag 본체 배지 시스템 연동)

- [ ] "시즌 챔피언" / "퍼펙트 세팅" / "신규 컬러 클리어"
- [ ] 자동 배지 획득 푸시 알림

## 3.3 운영자 의심 패턴 카드 (T-D2)

- [ ] 단시간 다중 완등 탐지
- [ ] 평소 안 풀던 색 클리어 탐지
- [ ] N이 커진 후 시간/시간 통계 신호로 룰 정착

## 3.4 다국어 (영어)

- [ ] i18n 셋업 (next-intl 또는 동등)
- [ ] 핵심 화면 영문 번역
- [ ] 해외 크루 도입 가능성 검토

## 3.5 통계 깊이

- [ ] 색별 완등률
- [ ] 세팅 회차 비교
- [ ] 개인 성장 그래프
- [ ] 시즌 종료 자동 아카이브 + 히스토리 페이지

## 3.6 Deferred 후보 재검토

- [ ] **T-D4** 점수 정책 marketplace (다른 크루 도입 시 viral)
- [ ] **T-D3** AR 오버레이 / AI 자동 인식 / 데일리 챌린지 / 햅틱 — 의식적 재평가
